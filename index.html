Aprenda, Crie e Inove com Robótica

A Oficina de Robótica é um espaço de aprendizado onde alunos desenvolvem criatividade, programação e tecnologia criando seus próprios robôs.

Sobre a Oficina

A robótica educacional ajuda estudantes a desenvolver pensamento lógico, trabalho em equipe e habilidades tecnológicas para o futuro.

💻 Programação

Aprenda lógica de programação usando linguagens como JavaScript, Python e Scratch.

⚙️ Eletrônica

Conheça sensores, motores, placas Arduino e circuitos eletrônicos.

🤖 Construção

Monte robôs inteligentes utilizando criatividade e inovação.

Projetos da Oficina

🚗 Robô Seguidor de Linha

Robô que utiliza sensores para seguir caminhos automaticamente.

🌱 Robô Sustentável

Projeto voltado para soluções ambientais usando tecnologia.

🏠 Casa Inteligente

Sistema automatizado utilizando sensores e programação.

Tecnologias Utilizadas

  • Arduino
  • JavaScript
  • Python
  • Scratch
  • Sensores
  • Motores
  • Impressão 3D
